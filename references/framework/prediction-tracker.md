# Prediction Accuracy Tracker — System Specification

> APA 리포트에서 생성된 예측/주장을 추적하고 정확도를 측정하는 시스템 설계.
> 이 문서는 향후 별도 스킬(prediction-tracker)로 구현될 때의 사양서 역할.
> Created: 2026-03-31

---

## 1. 추적 대상

리포트 섹션 중 예측성 주장이 포함되는 3개 섹션:

| 섹션 | 추적 내용 | 검증 주기 |
|------|-----------|-----------|
| S04 | 6개월 시사점 — 중기 방향 예측 | 월 1회 중간 점검, 6개월 후 최종 판정 |
| S05 | 전략 조정 (Build/Buy/Wait/Exit) | 3개월 후 1차 판정, 6개월 후 최종 |
| S08 | Tomorrow Watchlist — 단기 예측 | 익일 즉시 판정 |
| 시나리오 확률 | A/B/C 시나리오 확률 변동 | 월 1회 방향 검증 |

## 3. 정확도 계산

### 단기 정확도 (S08)
```
S08 Accuracy = (✅ + ⚠️×0.5) / (✅ + ❌ + ⚠️) × 100%
```
- 목표: 60% 이상 (초기 3개월)
- 장기 목표: 70% 이상

### 중기 정확도 (S04/S05)
```
Mid-term Accuracy = (✅ + ⚠️×0.5) / 판정 완료 건수 × 100%
```
- 6개월 후부터 측정 시작
- 목표: 50% 이상 (중기 예측은 본질적으로 어려움)

### 확신도별 적중률
```
Per-confidence Hit Rate = 해당 등급 적중 수 / 해당 등급 전체 수
```
- HIGH > MEDIUM > LOW 순으로 적중률이 높아야 정상
- 역전 시 확신도 기준 재조정 필요

## 5. 워크플로우 통합

### 리포트 생성 시 (report-generator)
1. S04, S05, S08 작성 시 각 예측에 ID 부여 (P-YYYYMMDD-N)
2. 확신도 등급 필수 명시
3. 예측 내용을 `outputs/predictions/daily/` 에 자동 저장

### 익일 스캔 시 (news-scanner)
1. 전일 S08 예측 3건 확인
2. 당일 뉴스와 대조하여 ✅/❌/⚠️ 판정
3. 판정 결과를 해당 예측 파일에 업데이트

### 월간 리뷰 시
1. 해당 월 전체 단기 예측 정확도 집계
2. 중기 예측 중간 점검
3. 시나리오 확률 변동 추이 검토
4. 확신도별 적중률 분석
5. 결과를 `outputs/predictions/monthly/` 에 저장

## 6. 구현 우선순위

| Phase | 내용 | 시기 |
|-------|------|------|
| **Phase 0 (즉시)** | 수동 추적 시작 — 매일 S08 예측을 md 파일로 기록 | 즉시 |
| **Phase 1** | report-generator에 예측 자동 추출 + 저장 로직 추가 | 1-2주 내 |
| **Phase 2** | news-scanner에 전일 예측 검증 로직 추가 | 2-4주 내 |
| **Phase 3** | prediction-tracker 독립 스킬 생성 (월간 리뷰 자동화) | 1-2개월 내 |
| **Phase 4** | accuracy-dashboard 자동 생성 (블로그/뉴스레터 공개용) | 3개월 내 |

## 7. 공개 가치

예측 정확도 추적은 다음 측면에서 차별화 자산:

- **신뢰도 구축**: "우리 예측의 70%가 적중했다"는 구독 전환의 핵심 논거
- **자기 교정**: 어떤 레이어/유형의 예측이 약한지 파악 → 분석 방법론 개선
- **프리미엄 차별화**: 정확도 데이터 자체가 Pro 구독자 전용 콘텐츠
- **콘텐츠 소재**: 월간 정확도 리뷰 → 블로그 포스트 + 뉴스레터 소재
