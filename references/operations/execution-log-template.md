# AI Power Atlas — Execution Log Template

> 그록의 LangSmith 관측성 개념 차용.
> 매일 파이프라인 실행 후 archive-manager가 이 파일에 추가 기록.
> 위치: outputs/execution-log.md (append-only)

---

## 사용 목적

- 파이프라인 실행 패턴 파악 (어느 단계에서 시간 소요)
- 오류 발생 빈도·유형 추적
- 월간 운영 효율 리뷰 근거
- 자동화 수준 측정 (Human 개입 시간 추적)
- **ARPU 추적** — 구독자 수보다 고객당 수익이 핵심 KPI (ChatGPT 2차 분석 차용)

---

## 일별 실행 로그 포맷

```markdown
## [YYYY-MM-DD] ([요일]) | [Focus Layer]

| 항목 | 내용 |
|------|------|
| 실행 시작 | HH:MM KST |
| 실행 완료 | HH:MM KST |
| 총 소요 시간 | N분 |
| Human 개입 시간 | N분 (검토·수정·발행) |
| 수집 소스 수 | N개 |
| 수집 기사 수 | N개 (필터 전) |
| S01 후보 기사 수 | N개 (Score ≥ 3) |
| 최종 선택 이벤트 | 3개 |
| 활성 피드백 루프 | [루프명 or 없음] |
| 발행 채널 | [뉴스레터 ✅/⬜ · 블로그 KO ✅/⬜ · 블로그 EN ✅/⬜ · PDF ✅/⬜] |
| 오류/이슈 | [없음 or 설명] |
| **유료 구독자 수** | N명 |
| **ARPU (이번 달)** | ₩N,NNN (유료 구독 수익 ÷ 유료 구독자) |
| **누적 유료 구독자** | N명 (목표: 500명) |
| 메모 | [선택사항] |
```

## 예시 항목

```markdown
## 2026-03-09 (월) | L1 + L2

| 항목 | 내용 |
|------|------|
| 실행 시작 | 09:15 KST |
| 실행 완료 | 09:47 KST |
| 총 소요 시간 | 32분 |
| Human 개입 시간 | 18분 (S01 이벤트 검토 10분 + 뉴스레터 발행 8분) |
| 수집 소스 수 | 12개 |
| 수집 기사 수 | 47개 (필터 전) |
| S01 후보 기사 수 | 8개 (Score ≥ 3) |
| 최종 선택 이벤트 | 3개 |
| 활성 피드백 루프 | L8→L1 (미국 칩 수출 규제 관련) |
| 발행 채널 | 뉴스레터 ✅ · 블로그 KO ✅ · 블로그 EN ✅ · PDF ⬜ |
| 오류/이슈 | 없음 |
| 메모 | 첫 실행일 — 기준점 |
```

## 월간 요약 포맷

```markdown
## 2026년 3월 실행 요약

| 지표 | 수치 |
|------|------|
| 총 실행 일수 | N일 |
| 평균 총 소요 시간 | N분 |
| 평균 Human 개입 시간 | N분 |
| 자동화율 | N% (1 - Human개입/총소요) |
| 총 수집 기사 | N개 |
| 평균 S01 후보 기사 | N개 |
| 오류 발생 횟수 | N회 |
| 완전 발행 완료일 | N일 (4채널 모두 ✅) |
```
