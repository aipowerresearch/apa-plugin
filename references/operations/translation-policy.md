# Translation Policy — 다국어 번역 품질 정책 (공통)

> EN(원문) → 모든 타겟 언어(KO/JA/ZH/ES/DE/FR/PT/AR/...) 번역에 공통 적용.
> 언어별 세부 어휘·직역체 사례는 부록 파일에서 관리: `translation-policy-{lang}.md`.

---

## 1. 자국어 우선 원칙 (절대 규칙)

타겟 언어로 번역 가능한 단어·표현은 **반드시 자국어로 작성**.
원어(영어)를 그대로 둘 수 있는 경우는 다음 5가지로 제한:

1. **고유명사**: 기업명, 제품명, 법령명, 지표명
2. **약어**: GPU, CPU, API, MCP, RAG, LLM, HBM, ARR, MRR 등
3. **기술 용어 중 자국어 번역이 불명확한 경우** (단, 가능한 한 자국어 표기 우선)
4. **금융·통화 단위**: $, USD 등 (단, 자국어 표기 가능 시 우선)
5. **인용·따옴표 안의 원문**

각 언어별 어휘 표는 `translation-policy-{lang}.md` 부록에서 관리.

## 2. 품질 평가 척도 (10점 만점, 모든 언어 공통)

| 항목 | 배점 | 평가 기준 |
|---|---|---|
| **충실성 (Fidelity)** | 3 | 원문의 모든 수치·고유명사·논리 구조 보존. 누락·왜곡 시 감점. |
| **자연스러움 (Fluency)** | 3 | 타겟 언어 어순·관용 표현 사용. 직역체·원어 어순 그대로·어색한 조사·관사 사용 시 감점. |
| **용어 적절성 (Term Appropriateness)** | 2 | 자국어 번역 가능 용어를 자국어로 작성. 부록의 "반드시 번역" 항목 위반 시 감점. |
| **문법·맞춤법 (Grammar)** | 1 | 띄어쓰기, 조사·관사, 어미 일치, 오탈자. |
| **톤 일관성 (Tone Consistency)** | 1 | 보고서 톤(격식체) 일관 유지. 문체 혼합 시 감점. |

**총점 8.0/10 이상 통과**

## 3. 검수 절차 (report-writer 스킬 내부, 모든 언어 동일)

### Step 1: 원문(EN) 작성
영어로 8섹션 완결.

### Step 2: 타겟 언어 1차 번역
`translation-policy-{lang}.md` 어휘 표 준수.

### Step 3: 자체 평가 (필수)
번역 직후 섹션별로 위 5개 항목 채점. 결과를 다음 형식으로 타겟 파일 말미에 HTML 주석으로 기록:

```markdown
<!--
## 번역 품질 자체 평가 — YYYY-MM-DD ({lang})

| 섹션 | 충실 | 자연 | 용어 | 문법 | 톤 | 합계 | 판정 |
|------|------|------|------|------|----|------|------|
| S01 Event 1 | 3 | 3 | 2 | 1 | 1 | 10.0 | PASS |
| S01 Event 2 | 3 | 2 | 1 | 1 | 1 | 8.0 | PASS |
| S03 | 3 | 1 | 1 | 1 | 1 | 7.0 | FAIL → 재번역 |
| ... |

전체 평균: X.X / 10
-->
```

### Step 4: 재번역 (FAIL 섹션)
8점 미만 섹션 식별 → 감점 사유 명시 → 재번역. 재평가 후 8점 이상 확인.

### Step 5: 자동 검수 (verify_daily.sh)
타겟 언어별로 `original_word_ratio` 검사 — 자국어 본문 내 원어(영문) 단어 비율이 임계값 이하인지 확인.
- 임계값: ≤ 15% (화이트리스트 = 고유명사·약어 제외 후)
- 임계값 초과 시 정책 위반 의심 → 재검토

### Step 6: 로그 (6점 미만 발생 시)
`outputs/_logs/translation-log-{lang}.md` (append-only)에 사유·재작성 횟수 기록.
동일 패턴이 반복되면 부록(`translation-policy-{lang}.md`) 어휘 표 확장.

## 4. 언어별 부록 파일

| 언어 | 부록 파일 | 상태 |
|---|---|---|
| 한국어 (ko) | `translation-policy-ko.md` | 활성 |
| 일본어 (ja) | `translation-policy-ja.md` | 향후 |
| 중국어 (zh) | `translation-policy-zh.md` | 향후 |
| 스페인어 (es) | `translation-policy-es.md` | 향후 |
| 독일어 (de) | `translation-policy-de.md` | 향후 |
| 프랑스어 (fr) | `translation-policy-fr.md` | 향후 |
| 포르투갈어 (pt) | `translation-policy-pt.md` | 향후 |
| 아랍어 (ar) | `translation-policy-ar.md` | 향후 |

각 부록 파일은 다음 5개 섹션 구조로 작성:

1. **자국어 우선 원칙 (언어별 세부)**
2. **반드시 번역해야 하는 어휘 표** (필수 자국어 변환 어휘 20~30개)
3. **자주 발생하는 직역체 사례 (Bad → Good)**
4. **언어 특수 규칙** (예: 한국어 격식체, 일본어 です/ます체, 중국어 简体/繁體, 스페인어 tú/usted 등)
5. **자동 검수 화이트리스트** (verify_daily.sh가 카운트 제외할 고유명사·약어 목록)

## 5. 정책 갱신

본 공통 정책은 모든 언어 운영 중 발견된 공통 패턴을 누적해 갱신.
언어별 부록은 각 언어 운영 중 발견된 패턴으로 독립 갱신.
references-editor 스킬로 수정 가능.
