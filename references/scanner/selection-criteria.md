# AI Power Atlas — Source Selection Criteria

> APA 소스 선정 기준 공식 문서. 모든 레이어·언어의 소스 선정에 적용되는 원칙.
> Created: 2026-03-23 | Owner: APA Editorial

---

## 1. 선정 목적 (Why We Source)

APA는 "무슨 일이 있었나"가 아니라 **"AI 산업 권력 구조가 어떻게 움직이는가"**를 분석한다.
소스 선정은 이 목적을 위해 존재한다. 단순 뉴스 집계(aggregation)가 아니라 **구조적 신호(structural signal) 포착**이 기준이다.

---

## 2. 1차 기준 — 소스 자격 요건 (Eligibility)

모든 소스는 아래 4개 요건을 모두 충족해야 한다.

| # | 요건 | 설명 | 예시 |
|---|------|------|------|
| E1 | **신호 관련성** | APA 10-Layer 프레임워크의 하나 이상의 레이어에 직접 연결되는 정보를 생산 | NVIDIA Blog → L1, Anthropic → L2, White House → L8 |
| E2 | **정보 원천성** | 인용·요약·재가공이 아닌 최초 정보 생산자(1차 소스) 또는 고유 분석을 보유한 전문 미디어 | 공식 블로그, 연구기관, 취재 기반 전문지 |
| E3 | **업데이트 빈도** | 레이어 관련 새로운 정보를 주 1회 이상 게재 | 공식 블로그, 전문 뉴스레터, 연구기관 |
| E4 | **접근 가능성** | 로봇 크롤링 또는 웹 검색으로 콘텐츠 헤드라인·요약 접근 가능 | 페이월 소스는 T1 우선 선정 후 접근 가능성 검토 |

---

## 3. 2차 기준 — Tier 분류 기준 (Tier Classification)

자격 요건을 통과한 소스를 아래 기준으로 Tier 분류한다.

### Tier 1 (매일 스캔 — 15개 정원)

**정의**: 해당 소스의 발행이 그 자체로 시장 이동 신호가 되는 원천 소스

기준:
- **1차 정보 독점성** — 해당 기관만이 발표할 수 있는 정보 생산 (예: OpenAI는 GPT 모델 발표를 자사 블로그에서만 먼저 한다)
- **Tier 1 플레이어 직접 채널** — APA 정의 L1~L2 핵심 기업의 공식 커뮤니케이션 채널
- **정책 1차 소스** — 법률·규제·정부 발표의 원문 출처
- **사실 오류율** — 과거 1년 내 주요 오보 이력 없음

→ T1 소스 리포팅 = 즉시 S01 핵심 사건 후보로 격상

### Tier 2 (격일 스캔 — 15개 정원)

**정의**: 고품질 분석 또는 취재력을 갖춘 전문 미디어·연구기관

기준:
- **분석 심도** — 단순 뉴스 전달이 아닌 레이어 간 연결 또는 구조적 해석 포함
- **전문성** — 특정 레이어(예: 반도체, 정책, VC) 전문 취재 체계 보유
- **리드 타임** — T1 소스 발표 후 24~48시간 내 심층 분석 발행 능력
- **독자 신뢰도** — 업계 전문가 구독 기반 보유 (검증 어려운 경우 편집자 판단)

### Tier 3 (주간 스캔 — 12개 정원)

**정의**: 학술, 리서치, 장기 트렌드, 지역 특화 소스

기준:
- **학술 검증성** — 피어리뷰 또는 저명 연구기관 발행
- **장기 시나리오 연관성** — APA S-Tracker(시나리오 A/B/C) 업데이트에 유효한 신호 생산
- **지역 커버리지** — 글로벌 T1/T2 소스가 커버하지 못하는 지역·언어 정보

## 4. 제외 기준 (Disqualification)

아래 중 하나라도 해당하면 소스 목록에서 제외한다.

| 코드 | 사유 |
|------|------|
| D1 | 확인되지 않은 정보의 1차 유포 이력 (오보, 오정보) |
| D2 | 특정 기업·진영의 홍보 목적 콘텐츠 위주 (PR/마케팅 채널) |
| D3 | 콘텐츠가 타 소스의 단순 재가공 위주 (원천성 결여) |
| D4 | 업데이트 빈도 월 2회 미만 (실질적 활동 중단) |
| D5 | APA 10-Layer 프레임워크와 교차점 없음 |

## 5. 선정 프로세스 (Process)

```
1. 후보 소스 발견 → E1~E4 요건 체크 (4개 모두 충족 여부)
2. Tier 분류 기준 적용 → T1 / T2 / T3 배정
3. 현재 정원 확인 (T1: 15개, T2: 15개, T3: 12개)
4. 정원 초과 시: 기존 소스 중 최저 기여도 소스와 교체 여부 판단
5. source-list.md 업데이트 + 변경 사유 기록
6. news-scanner 키워드/쿼리 업데이트 반영
```

## 6. 소스 품질 평가 기준 (Quality Dimensions)

소스 선정·유지·교체 판단에 사용하는 8개 품질 차원. 각 차원은 월간 검토 시 0~5점으로 평가한다.

| # | 차원 | 정의 | 평가 방법 |
|---|------|------|----------|
| Q1 | **신빙성 (Credibility)** | 발행 기관의 사실 보도 신뢰도. 오보 이력, 정정 빈도, 업계 평판 | 과거 12개월 내 주요 오보·정정 사례 확인 |
| Q2 | **진정성 (Authenticity)** | 독립적·원천적 정보 생산 여부. 특정 기업·이해관계 대변이 아닌 편집 독립성 | 주요 기사의 광고주·투자자 이해충돌 여부 확인 |
| Q3 | **최신성 (Currency)** | 발행 속도와 시의성. 사건 발생 후 얼마나 빨리, 정확하게 보도하는가 | 최근 10개 주요 사건의 보도 리드 타임 측정 |
| Q4 | **통합성 (Comprehensiveness)** | 레이어 내 핵심 토픽을 빠짐없이 커버하는 범위의 넓이 | 해당 Tier 내 다른 소스와 비교 시 커버리지 중복/격차 분석 |
| Q5 | **분석 심도 (Analytical Depth)** | 단순 사실 전달을 넘어 구조적 해석·맥락·인과관계를 제공하는가 | APA S01~S08 섹션 생성에 실제로 얼마나 기여했는가 |
| Q6 | **접근 안정성 (Access Stability)** | 크롤링·웹 검색 접근이 지속적으로 가능한가. 페이월 변경·URL 변경 빈도 | 최근 30일 스캔 성공률 추적 |
| Q7 | **독자 신뢰 지수 (Audience Trust)** | 해당 소스를 인용하는 2차 소스의 수준과 빈도 (간접 신뢰도 측정) | T1 소스가 해당 소스를 인용하는지 여부 |
| Q8 | **신규성·비대체성 (Uniqueness)** | 다른 소스로 대체 불가능한 고유 정보를 생산하는가 | 해당 소스 제거 시 S01~S08 커버리지에 공백이 생기는지 테스트 |

**최저 유지 기준**: Q1+Q2 각각 3점 이상 필수. 나머지 6개 합산 평균 3점 이상. 어느 하나가 1점이면 즉시 교체 심의.

## 7. 정기 검토 루틴 (Review Routine)

### 7.1 월간 검토 — 매월 말 주 실행 (핵심 루틴)

**목적**: 현재 소스 풀의 품질 유지 + 신규 소스 발굴

**실행 주체**: Claude (자동 실행) + 박대표님 최종 승인

**월간 검토 절차 (6단계)**:

```
Step 1 — 현재 소스 품질 평가 (Q1~Q8)
  · 각 소스를 8개 차원에서 0~5점 평가
  · 최저 유지 기준 미달 소스 → "교체 후보" 지정

Step 2 — 기여도 분석
  · 직전 4주간 각 소스가 S01~S08 생성에 실제로 기여한 횟수 집계
  · 기여도 하위 20% (T1: 3개, T2: 3개, T3: 2개) → "저활용 후보" 지정

Step 3 — 신규 소스 광범위 탐색
  · 탐색 범위: 공식 기업 채널, 학술/연구기관, 전문 미디어, 뉴스레터, arXiv 등
  · 탐색 방법: APA 10-Layer 키워드 기반 웹 검색 + 기존 T1 소스 인용 출처 역추적
  · 최소 탐색 후보: T1 5개, T2 10개, T3 5개 신규 후보 검토

Step 4 — 교체 판단 매트릭스
  · 교체 후보 소스 vs 신규 후보 소스를 Q1~Q8 기준으로 1:1 비교
  · 신규 소스가 기존 소스보다 총점 10% 이상 우위 시 교체 권고

Step 5 — 변경 실행
  · source-list.md 업데이트
  · 제거 소스: 제거 사유 + 날짜 기록
  · 신규 소스: 추가 사유 + Tier + 레이어 연관성 기록
  · news-scanner 키워드/쿼리 업데이트 반영

Step 6 — 검토 리포트 생성
  · 저장 경로: APA/outputs/meta/YYYY-MM_source-review.md
  · 내용: 평가 점수표 + 변경 사항 + 다음 달 모니터링 포인트
```

### 7.2 주간 모니터링 — 매주 일요일 위클리 리포트와 함께

| 항목 | 기준 | 조치 |
|------|------|------|
| T3 소스 신호 생산 여부 | 2주 연속 관련 신호 0건 | "월간 검토 교체 후보" 플래그 |
| 스캔 접근 실패 | 7일 연속 접근 불가 | 즉시 대체 소스 투입 |
| 오보·정정 감지 | T1/T2 소스에서 주요 오정보 발생 | Q1 점수 하향 + 교차검증 강화 |

### 7.3 분기 검토 — 매 분기 초

- 10-Layer 프레임워크 변경 반영 여부 확인
- 레이어별 소스 배분 재조정 (특정 레이어 소스 편중 방지)
- 신규 진입 플레이어 (새로운 AI 기업 공식 채널) T1 편입 여부 판단
- 지역 소스 확장 로드맵(product-backlog.md BACKLOG-001) 진행 상황 점검

### 7.4 연간 검토 — 매년 1월

- 전체 소스 목록 zero-base 재검토
- source-list.md Tier 정원 조정 여부 검토 (현재: T1×15, T2×15, T3×12)
- 연간 소스 기여도 종합 분석 리포트 생성
- 다음 연도 소스 전략 수립

---

### 7.5 월간 검토 실행 트리거

다음 중 하나라도 해당하면 정기 주기 외 **즉시 검토** 실행:

| 트리거 | 조치 |
|--------|------|
| T1 소스가 서비스 중단·도메인 변경 | 48시간 내 대체 소스 확보 |
| 신규 AI 기업 공식 채널 등장 (예: 새 파운데이션 모델 기업) | 즉시 T1 편입 심의 |
| 특정 소스에서 반복 오보(월 2회 이상) 발생 | Q1 1점 처리 → 즉시 교체 심의 |
| 새로운 레이어 또는 서브레이어 프레임워크 추가 | 해당 레이어 소스 공백 여부 확인 |

## 8. 품질 게이트 (Quality Gates) — 일간 적용

소스 스캔 후 S01 핵심 사건 등록 전 아래 3개 게이트를 통과해야 한다.

| 게이트 | 기준 |
|--------|------|
| **G1: 교차 검증** | T2 이상 소스 2개 이상이 동일 사건을 독립적으로 보도/확인 |
| **G2: 레이어 귀속** | 해당 사건이 10-Layer 중 하나 이상에 명확하게 귀속 가능 |
| **G3: 권력 이동 테스트** | "이 사건이 없었다면 AI 권력 구조가 달랐을까?" → Yes여야 S01 등재 가능 |

## 9. 영어 우선 원칙 (English-First Principle)

> **모든 APA 발행물의 1차 언어는 영어이다. 이는 절대 불변의 원칙이다.**

소스 선정에도 이 원칙이 적용된다:

- T1/T2의 글로벌 표준 소스는 영어 기반으로 구성하며, 이 소스에서 생산된 신호가 모든 언어판 리포트의 공통 기반이 된다.
- 한국어, 일본어 등 언어별 추가 소스는 T2 하단~T3에 배치되며, 해당 언어판 리포트의 지역 특화 섹션 보완 용도로 사용된다.
- 언어별 추가 소스가 글로벌 T1/T2 소스와 동등한 비중으로 취급되지 않는다.
