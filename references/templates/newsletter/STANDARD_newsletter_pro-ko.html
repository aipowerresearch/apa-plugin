L7 + L6

베조스 Project Prometheus, $38B 밸류에 $10B 클로징 임박

제프 베조스와 비크람 바자즈가 공동 창업한 Project Prometheus가 BlackRock·JPMorgan을 앵커 LP로 하는 $10B 라운드를 $38B 밸류에 마무리 수순에 들어갔다 — 2025년 11월 $6.2B 시드 이후 단 6개월 만이다. 이 연구소의 미션 — "물리 세계를 이해하는 모델" — 은 월드 모델, 파운데이션 로보틱스 모델, 산업용 에이전트를 단일 스택으로 통합한다. 누적 자본 배치는 $16B를 상회한다. 이번 라운드는 2026년 2분기 구조를 확정한다: 피지컬 AI 자본이 3개 극(Prometheus·Figure AI $39B·Waymo)으로 집중되고, 1분기 글로벌 VC $330.9B 중 AI 비중 80% 안에서 자본이 LLM 중심에서 피지컬 AI 중심으로 재배치되는 변곡점을 표시한다. 베조스-바자즈 공동 CEO 구조는 Prometheus를 Figure AI 급에 근접한 두 번째 집중 극으로 끌어올린다. 이제 자본은 L6(로보틱스·자율주행·산업 에이전트)로 흐르고, 여기서 생성되는 월드 모델 학습 데이터가 상류 L2 파운데이션 모델 경쟁 구도를 재편한다.

L7 + L5

Cursor $2B 라운드 $50B 밸류 오버서브스크라이브드

Cursor의 모기업 Anysphere가 Andreessen Horowitz와 Thrive Capital이 공동 리드하고 NVIDIA가 전략적 공동 투자자, Battery Ventures가 신규로 참여하는 $50B pre-money $2B+ 라운드를 협상 중이다. $100M ARR (2025.1) → $1B (2025.11) → $2B (2026.2)로 이어지는 13개월의 $2B ARR 궤적은 B2B SaaS 역사상 최단 — Slack·Zoom·Snowflake를 모두 능가한다. 이번 라운드는 5개월 만에 밸류를 2배로 끌어올렸고 이미 초과 청약 상태다. AI 코딩 에이전트 레이어의 winner-take-all 구조가 확정되며, GitHub Copilot·Replit·Codeium에 대한 가격·기능 재진입 압력이 심화된다. NVIDIA의 전략적 참여는 GPU 공급 확약을 시사하며, a16z·Thrive 공동 리드는 Cursor를 Microsoft GitHub Copilot 락인에 정면으로 맞서는 독립 스택으로 재포지셔닝한다. Cursor 엔터프라이즈 티어 확대에 따라 Anthropic·OpenAI API 소비가 상류에서 가속되며, L7→L2 루프를 통해 모델 벤더 수익 구조를 재편한다.

임팩트 5 · 권력 +2(Cursor/Anysphere/a16z) / -1(Copilot·Replit·Codeium) · 단기 0–3개월 · L7→L2 활성
 

L8 + L7

MATCH법 개정본 + GAIN AI법 NDAA 편입

상원의원 Pete Ricketts와 Andy Kim이 4월 8일 MATCH법을 발의했고, 4월 16일 회람된 개정본은 극저온 에칭 국가별 일괄 금지와 서비스 라이선스 자동 거부 추정을 완화하면서도 우려국을 대상으로 한 DUV 몰입 리소그래피·cryo 에칭 장비(선단·레거시 노드)의 핵심 금지 조항은 유지했다. GAIN AI법은 2026 NDAA 상원안에 편입되어 미국 바이어의 우선 구매권(right of first refusal)을 성문화한다 — 수출 라이선스 발급 전 15영업일 공지와 비슷한 국내 주문이 미충족 상태임을 입증하는 인증을 요구한다. 1월 15일 BIS 최종안(H200·MI325X 건별 심사 + 25% 관세)에 중첩되면서, 입법 층위는 순수 행정 재량을 해체하고 되돌리기 어려운 법적 기반을 구축한다. 수출 라이선스 불확실성이 NVIDIA·AMD 중국 매출을 할인하고 2분기 실적 가이던스 변동성을 확대(L8→L7)하며, 중국의 국산 칩 대체 수요가 SMIC·화웨이 밸류에이션 프리미엄을 견인(L8→L1)한다.

S03 S03  ·  Cross-Layer Cascadenbsp;·S03  ·  Cross-Layer Cascadenbsp; 레이어 간 연쇄 효과 ◆
  오늘 3대 이벤트는 하나의 자기 강화 연쇄를 형성한다. L7 자본에서 Prometheus $10B/$38B 라운드가 피지컬 AI 자본을 하류 L6 로보틱스·자율 시스템으로 재분배하면, 거기서 생성되는 월드 모델 학습 데이터가 상류 L2 파운데이션 모델 경쟁으로 환류한다. 동시에 Cursor $2B/$50B 라운드는 L7 코딩 에이전트 자본을 Anysphere로 집중시키고, Anysphere의 모델 지출이 상류 Claude·GPT-5 API 매출을 견인(L7→L2)한다. 직교 축에서 L8 MATCH+GAIN 입법 중첩은 NVIDIA·AMD 중국 매출을 제약(L8→L7)하고 수요를 SMIC·화웨이 밸류(L8→L1)로 재분배한다. 순효과: 자본은 이분화된다 — LLM 중심 집중(OpenAI·Anthropic)이 지속되는 동시에 피지컬 AI 극(Prometheus·Figure AI)이 신설되며, 수출 통제는 GPU 공급을 국내 AI 바이어로 돌리고 하이퍼스케일러의 중국 매출을 압축한다.
S04 S04  ·  Stakeholder Power Shiftnbsp;·S04  ·  Stakeholder Power Shiftnbsp; 이해관계자 권력 변화 ◆
  이해관계자 권력 이동은 세 축으로 집중된다. (1) 피지컬 AI 승자 — 베조스(+3)와 Prometheus/Figure AI/Waymo 3극이 구조적 자본 우위를 얻고, 독립 로보틱스·standalone 월드모델 스타트업은 자본 집중으로 포지셔닝 권력을 잃는다(-1). (2) AI 코딩 통합 — Cursor/Anysphere/a16z(+2)가 Microsoft GitHub Copilot 하이퍼스케일러 락인으로부터 개발자 도구 통제점을 이탈시키고, Replit·Codeium은 가격·기능 동등성 압박에 직면한다(-1). (3) 반도체 정책 — 미국 장비 제조사·국내 AI 바이어(+2)가 우선 구매권과 수출 라이선스 프리미엄을 획득하고, 중국 팹 확장과 NVIDIA 중국 매출 믹스는 구조적 압축에 직면한다(-2). 근저의 변화: 자본·규제 권력이 단일 행정부 교체로 되돌릴 수 없는 3블록 구조(미국 피지컬 AI / 미국 코딩 에이전트 스택 / 중국 대체)를 공식화한다.
